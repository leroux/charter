Path chaining with `|` does not work after an array path. On the same document as `[{"c":[{"a":10.11}]},{"c":[{"a":11.11}]}]`, `@reverse|0|c|0|a` should be `11.11` and `#.c|#` should be `2` (the pipe applies to the array `#.c` produced). Chaining should also work after a nested key, for example `info.friends|0|first` on `{"info":{"friends":[{"first":"Dale"}]}}`, and an escaped character in a key after a pipe, as in `@ugly|i\nfo|friends.0.first` (the `\n` there is an escaped `n`), should still find `info`. Please make the pipe work anywhere a path component can end, with tests.
